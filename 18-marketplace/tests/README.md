# Automated QA

Run:

```bash
./tests/qa-static.sh
./tools/build-release.sh
```

The repository suite validates PHP/JavaScript syntax, CSS structure, state machines, zero-commission and owner-boundary contracts, required schemas/routes/events/privacy controls, forbidden parallel chat tables, documentation and package integrity. It does not replace real WordPress/Hostinger, database migration, browser, accessibility, load, backup/restore or security testing.
